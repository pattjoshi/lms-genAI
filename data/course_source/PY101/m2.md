# Data Structures in Python

Python ships with powerful built-in collections. Choosing the right one makes code shorter, faster and easier to understand.

## Lists and Tuples

Prerequisites: Variables and Data Types.

A list is an ordered, mutable collection written with square brackets, for example `marks = [72, 85, 90]`. Items are accessed by index starting at 0, so `marks[0]` is 72 and `marks[-1]` is the last item. Lists can grow and shrink with `append()`, `insert()`, `pop()` and `remove()`.

Slicing returns part of a list: `marks[1:3]` gives the items at index 1 and 2. The end index is excluded, which is a frequent source of off-by-one errors.

A tuple looks similar but uses parentheses and is immutable: once created, its items cannot change. Tuples are used for fixed groups of values such as coordinates `(x, y)` and for returning several values from a function. Because they are immutable, tuples can be used as dictionary keys while lists cannot.

## Dictionaries and Sets

Prerequisites: Lists and Tuples.

A dictionary stores key-value pairs, for example `student = {"name": "Riya", "city": "Lucknow"}`. Looking up a value by key with `student["name"]` is very fast, on average constant time O(1), because dictionaries are implemented as hash tables. Asking for a missing key raises a KeyError; `student.get("age", 0)` returns a default instead.

Keys must be hashable, which means immutable types such as strings, numbers and tuples. Since Python 3.7, dictionaries keep insertion order.

A set is an unordered collection of unique items, for example `{"python", "sql"}`. Sets remove duplicates automatically and support fast membership tests with `in`. Set operations mirror mathematics: union `|`, intersection `&` and difference `-`. A typical use is finding students enrolled in both of two courses with an intersection.

## List Comprehensions

Prerequisites: Lists and Tuples, Control Flow.

A list comprehension builds a new list from an existing sequence in one readable line. The pattern is `[expression for item in sequence if condition]`. For example, `[m for m in marks if m >= 50]` keeps only passing marks, and `[m * 1.1 for m in marks]` scales every mark.

Comprehensions replace the common three-step pattern of creating an empty list, looping, and appending. They are usually faster than the equivalent loop because the iteration runs inside Python's C implementation.

The same syntax creates dictionaries and sets: `{name: len(name) for name in names}` is a dictionary comprehension. Using round brackets instead of square brackets creates a generator expression, which produces items lazily one at a time and saves memory for large data.

Keep comprehensions short. If one needs nested loops and several conditions, a normal for loop is usually clearer.
