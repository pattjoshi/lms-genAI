# Supervised Learning

In supervised learning the model learns from examples that already have the correct answer, called labels. Regression predicts a number; classification predicts a category.

## Linear Regression

Prerequisites: Linear Algebra Basics, Derivatives.

Linear regression predicts a number as a weighted sum of input features plus a bias: y = w1 x1 + w2 x2 + ... + b. With one feature it is a straight line, where w is the slope and b the intercept. For example, predicting a final exam score from hours studied.

The model is trained by choosing weights that make predictions close to the true values. Closeness is measured by a loss function; for regression the usual choice is Mean Squared Error (MSE), the average of the squared differences between predictions and true values. Squaring makes large errors count much more than small ones and keeps the loss positive.

For small problems the best weights can be computed directly with a formula called the normal equation. For large datasets and for almost every other model, the weights are found iteratively with gradient descent.

Linear regression assumes a roughly linear relationship. Plotting the residuals, the differences between predictions and true values, is a quick way to check whether that assumption holds.

## Logistic Regression

Prerequisites: Linear Regression, Probability Basics.

Despite its name, logistic regression is a classification model. It computes the same weighted sum as linear regression and then passes it through the sigmoid function, which squashes any number into the range 0 to 1. The output is read as a probability, for example the probability that a student will pass.

A decision threshold, usually 0.5, turns the probability into a class: above the threshold predicts "pass", below predicts "fail". Changing the threshold trades false positives against false negatives.

Logistic regression is trained with binary cross-entropy loss, also called log loss, which heavily penalises confident wrong predictions. MSE is not used because combined with the sigmoid it makes training slow and unstable.

The learned weights are interpretable: a positive weight increases the odds of the positive class. Extending the model to more than two classes uses the softmax function instead of the sigmoid.

## Gradient Descent

Prerequisites: Derivatives, Linear Regression.

Gradient descent is the algorithm that trains most machine learning models. It starts with random weights and repeats one step: compute the gradient of the loss with respect to each weight, then move each weight a small amount in the opposite direction of its gradient, because the gradient points uphill and we want to go downhill.

The size of the step is controlled by the learning rate. If the learning rate is too large, the loss jumps around or even grows; if it is too small, training takes a very long time. Values such as 0.01 or 0.001 are common starting points.

Batch gradient descent uses the whole dataset for each step. Stochastic gradient descent (SGD) uses one example at a time, and mini-batch gradient descent uses small groups such as 32 examples, which is the standard compromise between speed and stability.

Training stops after a fixed number of passes over the data, called epochs, or when the loss stops improving. Gradient descent can get stuck in a local minimum for non-convex losses, which is one reason improved optimizers such as Adam were developed.
