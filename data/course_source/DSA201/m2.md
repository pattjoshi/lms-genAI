# Linear Data Structures

Linear data structures store items in a sequence. Choosing between them is a question of which operations need to be fast.

## Arrays

Prerequisites: Big-O Notation.

An array stores elements in one contiguous block of memory. Because the address of element i can be computed directly, access by index is O(1). This also makes arrays cache-friendly and fast to scan.

Inserting or deleting in the middle is O(n), because every later element must shift. Searching an unsorted array is O(n); if the array is sorted, binary search finds an element in O(log n).

A static array has a fixed size. A dynamic array, such as a Python list or a Java ArrayList, grows automatically: when it is full, it allocates a bigger block, typically about double the size, and copies the elements over. A single resize costs O(n), but because it happens rarely, appending is O(1) amortized.

Two-dimensional arrays store grids and matrices. Common array techniques in interviews include the two-pointer technique and the sliding window, which turn many O(n squared) problems into O(n).

## Linked Lists

Prerequisites: Arrays.

A linked list stores each element in a separate node that holds the value and a pointer to the next node. The list keeps a pointer to the first node, called the head. Nodes can live anywhere in memory.

In a singly linked list each node points only to the next node; in a doubly linked list it also points to the previous node, which allows moving backwards and deleting a node in O(1) when you already hold a pointer to it.

Inserting or deleting at the head is O(1), with no shifting of elements. But access by position is O(n), because you must follow the pointers from the head; there is no direct indexing. Linked lists also use extra memory for pointers and are less cache-friendly than arrays.

Classic techniques include reversing a list in place by re-pointing nodes, and detecting a cycle with Floyd's algorithm, which moves a slow pointer one step and a fast pointer two steps: if they ever meet, there is a cycle.

## Stacks and Queues

Prerequisites: Arrays, Linked Lists.

A stack is Last In, First Out (LIFO): the last item added is the first removed, like a pile of plates. Its operations are push (add on top), pop (remove from top) and peek, all O(1). Stacks power the function call stack, undo features, and checking balanced brackets in expressions.

A queue is First In, First Out (FIFO): items leave in the order they arrived, like a line at a ticket counter. Its operations are enqueue (add at the back) and dequeue (remove from the front). Queues are used for task scheduling, print jobs and breadth-first search.

Both can be built on arrays or linked lists. A naive array queue makes dequeue O(n) because items shift, so implementations use a circular buffer or a linked list. In Python, use a list as a stack, but use collections.deque as a queue, since list.pop(0) is O(n).

A deque (double-ended queue) supports adding and removing at both ends in O(1). A priority queue removes the item with the highest priority first and is usually implemented with a heap.
