# Training Neural Networks

Training adjusts millions of weights so the network's predictions match the labels. This module explains how gradients are computed, what is being minimised, and how the update step is done.

## Backpropagation

Prerequisites: Chain Rule, Gradient Descent, Activation Functions.

Backpropagation is the algorithm that computes the gradient of the loss with respect to every weight in a neural network. Training then uses those gradients in gradient descent.

It works in two passes. In the forward pass, the input flows through the network layer by layer, and each layer stores its intermediate values. The loss is computed at the end. In the backward pass, the algorithm starts at the loss and moves backwards through the layers, applying the chain rule at each step: the gradient arriving from the layer above is multiplied by the local derivative of the current layer. Each weight's gradient is obtained along the way.

The key efficiency trick is reuse: gradients computed for a later layer are reused for earlier layers instead of being recomputed, so one backward pass costs roughly the same as one forward pass.

Common problems are vanishing gradients, where repeated multiplication by small derivatives shrinks the gradient so early layers barely learn, and exploding gradients, where it grows uncontrollably. ReLU activations, careful weight initialisation, batch normalisation and gradient clipping are the standard remedies. Modern frameworks such as PyTorch implement backpropagation automatically through automatic differentiation (autograd).

## Loss Functions

Prerequisites: Probability Basics.

A loss function measures how wrong the network's predictions are with a single number. Training means minimising it. The choice of loss depends on the task.

For regression, Mean Squared Error is standard; Mean Absolute Error is more robust when the data contains outliers. For binary classification, binary cross-entropy is used together with a sigmoid output. For multi-class classification, categorical cross-entropy is used together with a softmax output.

Cross-entropy compares the predicted probability distribution with the true one. If the true class receives probability p, the loss for that example is minus the logarithm of p. A confident correct prediction (p close to 1) gives a loss near 0, while a confident wrong prediction (p close to 0) gives a very large loss. This strong penalty is why cross-entropy trains classifiers faster than MSE.

The loss used for training is not always the metric you report. You might train with cross-entropy but report accuracy or F1 to stakeholders.

## Optimizers

Prerequisites: Gradient Descent, Backpropagation.

An optimizer decides how to update the weights once backpropagation has produced the gradients. Plain stochastic gradient descent (SGD) subtracts the learning rate times the gradient.

Momentum improves SGD by keeping a running average of past gradients, like a ball rolling downhill that builds up speed. It moves faster through flat regions and damps oscillations in narrow valleys.

RMSProp adapts the learning rate for each weight by dividing by a running average of recent squared gradients, so weights with consistently large gradients take smaller steps.

Adam, short for Adaptive Moment Estimation, combines momentum and RMSProp and corrects their bias in early steps. Its usual defaults are a learning rate of 0.001, beta1 of 0.9 and beta2 of 0.999, and it works well on most problems with little tuning, which makes it the most common default optimizer.

A learning rate schedule changes the learning rate during training, for example warming up for the first steps and then decaying it. Even with Adam, the learning rate is usually the most important hyperparameter to tune.
